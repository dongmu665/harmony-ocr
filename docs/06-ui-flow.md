# UI Flow

## V1.0 页面与流程

1. 启动页: 检查本地会话，决定进入首页或登录页。
2. 登录页: 输入账号密码，登录成功后进入首页。
3. 注册页: 创建账号，确认用户协议和隐私政策。
4. 首页: 提供拍照识别、相册识别、历史入口和我的入口。
5. 拍照识别: 调起相机采集图片。
6. 相册识别: 从相册选择图片。
7. 图片预览页: 展示待识别图片并确认。
8. 图片裁剪页: 调整 OCR 识别区域。
9. OCR 识别中状态: 显示处理进度、耗时和取消或重试状态。
10. OCR 结果页: 展示识别文本、保存、复制、编辑和清理入口。
11. 文本编辑: 修改 OCR 文本内容。
12. 文本复制: 复制当前文本到系统剪贴板。
13. 文本格式清理: 去除多余换行、空格和简单噪声。
14. 保存历史: 保存图片引用、识别文本、清理文本和来源。
15. 历史列表页: 分页查看当前用户历史。
16. 历史详情页: 查看图片、文本、来源、时间和收藏状态。
17. 收藏记录: 在详情或列表中切换收藏。
18. 搜索历史: 按关键字搜索历史记录。
19. 我的页面: 展示账号、设置、协议、反馈和注销入口。
20. 设置页: 管理默认选项、缓存和账号安全。
21. 用户协议页: 展示用户协议。
22. 隐私政策页: 展示隐私政策。
23. 账号注销页: 说明注销影响并进行身份确认。
24. 数据删除确认页: 二次确认删除或匿名化个人数据。
25. 用户反馈页: 填写反馈内容和联系方式。

## AI 相关页面与入口

1. AI 设置页: 管理 BYOK AI 配置。
2. 新增 AI 供应商配置页: 填写供应商名称、API Base URL、模型名称和启用状态。
3. API Key 输入页: 输入用户自带 API Key，并提示安全存储方式。
4. 测试连接按钮: 验证 API Base URL、模型和 API Key 是否可用。
5. 默认 AI 配置选择: 选择 OCR 结果页默认使用的 AI 配置。
6. OCR 结果页中的 AI 功能入口:
   - AI 纠错
   - AI 摘要
   - AI 翻译
   - 智能排版
   - 转 Markdown
7. 第三方 AI 隐私提示弹窗: 在发送 OCR 文本给第三方前提示用户并取得确认。

## 核心流程

拍照或相册选择图片后，用户进入预览和裁剪流程。确认后执行 OCR，结果页支持编辑、复制、格式清理、保存历史和后续 AI 操作。登录用户的历史记录可同步到云端；游客只能保留本地能力。

## 游客与登录态差异

- 游客可以进入 OCR 主流程，但历史记录仅保存在本地临时空间。
- 游客尝试云端同步时，应引导登录或注册。
- 登录用户保存历史后，应显示同步状态。
- 同步失败时，应提示失败原因并允许重试。
- 用户注销或数据删除确认页必须说明历史记录、文件对象、设备信息和 Token 的处理结果。
