# Test Plan

## 1. 后端单元测试

覆盖 service、domain、security、validation、ownership check、token refresh 和数据删除策略。

## 2. 后端接口测试

覆盖 Auth、User、Record、File、Feedback API 的成功、失败、鉴权和越权场景。

## 3. 前端手工测试

覆盖 HarmonyOS 页面跳转、相机、相册、裁剪、OCR 状态、结果编辑、复制、保存和设置。

## 4. 前后端联调测试

覆盖登录、Token 刷新、历史同步、文件上传、历史查询、收藏、搜索和删除。

同步测试必须覆盖按 `updated_after` 增量拉取、软删除同步、登录用户才能同步、游客无法同步和用户不能同步到他人记录。

## 5. 安全测试

覆盖密码哈希、JWT secret、Refresh Token 撤销、越权访问、上传校验和敏感日志。

## 6. 隐私测试

覆盖用户协议、隐私政策、第三方 AI 提示、账号注销、数据删除和 API Key 脱敏。

## 7. 弱网测试

覆盖 OCR 超时、上传失败、同步失败、Token 刷新失败和重试提示。

## 8. 文件上传测试

覆盖 MIME 类型、扩展名、大小限制、checksum、对象存储失败和用户归属校验。

## 9. OCR 测试

覆盖拍照、相册、裁剪、成功、失败、低质量图片、空文本图片和耗时记录。

## 10. 回归测试

每次非平凡功能变更后回归注册登录、OCR 主流程、历史记录和资源隔离。

## 11. 账号注销测试

覆盖注销确认、Token 失效、个人数据删除或匿名化、文件对象处理和重复注销。

## 12. 数据删除测试

覆盖历史记录、文本块、文件对象、Refresh Token、设备信息和审计日志的删除或匿名化规则。

数据删除测试还必须覆盖注销后 Token 失效、注销后访问用户资源失败、MinIO 文件删除或待清理标记、审计日志去标识化。

## 13. BYOK AI 测试

覆盖受保护的 Provider 配置接口、后端加密存储、脱敏响应、连接测试、AI 功能、超时、隐私提示和日志脱敏。不得把尚未实现的设备侧安全存储作为已通过能力。

## 14. 后端代理 AI 安全测试

现有测试应持续覆盖 API Key 加密存储、脱敏返回、Provider 目标协议与私网地址限制，以及多 Provider contract。生产 Provider chain、调用审计、DNS 重绑定、重定向限制和完整出站策略仍需补充集成测试。

## 能力回归测试

- 体验增强、OCR 与 AI、运营能力不得削弱核心认证、资源归属、OCR、历史记录和数据删除测试。
- 未配置外部 OCR 或 AI Provider 时，基础流程必须保持可运行，并明确标记不可用或降级状态。
- 管理、会员、批量、导出和 AI 接口必须分别覆盖普通用户越权、跨用户资源访问和敏感字段泄露场景。
