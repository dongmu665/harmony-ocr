# Product Overview

## 1. 产品定位

基于 HarmonyOS 的智能图片文字识别与云端历史管理系统是一款面向真实上线场景的移动端 OCR 产品。本产品不是简单 OCR Demo，而是由图片文字识别、文本处理、云端历史管理、用户账号体系和可选 AI 增强组成的完整产品。

## 2. 目标用户

- 需要从票据、截图、书页、公告、合同片段中快速提取文字的普通用户。
- 需要长期保存、检索和同步识别结果的学习、办公和资料整理用户。
- 希望使用 AI 对 OCR 文本做纠错、摘要、翻译和排版的进阶用户。

## 3. 核心价值

- 降低图片文字转可编辑文本的操作成本。
- 让 OCR 结果可以编辑、复制、清理格式、保存和跨设备同步。
- 通过账号体系和云端历史记录，使识别结果具备长期管理价值。
- 支持端侧与后端 OCR、BYOK AI，并为更复杂的识别和文档处理能力保留扩展空间。

## 4. 业务场景

- 拍照识别纸质文档、课堂板书、会议资料和线下公告。
- 从相册截图或图片中提取可复制文本。
- 对识别结果进行格式清理、编辑和保存。
- 登录后跨设备查看云端历史记录。
- 使用用户自带 API Key 对 OCR 文本进行 AI 纠错、摘要、翻译、智能排版和 Markdown 转换。

## 5. 第一版产品边界

V1.0 聚焦基础上线能力：注册登录、拍照识别、相册识别、图片预览裁剪、OCR、文本处理、历史记录、云端同步、用户协议、隐私政策、账号注销和数据删除。

## 6. 不做什么

- V1.0 不做会员额度、Web 管理后台、后端 AI 代理和 PaddleOCR 服务化。
- 当前 BYOK 使用后端托管模式，API Key 必须加密保存且不得明文返回；纯端侧密钥模式尚未实现。
- 不把图片二进制数据写入 MySQL。

## 7. 长期演进方向

当前开源快照已经覆盖批量识别、扫描型 PDF 输入、文本与 PDF 导出、AI Provider 管理、后端 AI 调用、会员额度和 Web 管理台。后续演进重点包括表格识别、可搜索 PDF 完整工作流、云端文件夹、多设备冲突合并、生产级密钥管理和规模化运行能力。
